REST transcription

    
Endpoint: POST /api/transcribe. Send base64 WAV or base64 raw pcm_s16le. Audio must be 16 kHz mono.

    
{
  "audio": {
    "format": "wav",
    "encoding": "base64",
    "data": "UklGRiQAAABXQVZF..."
  },
  "context": {
    "device_id": "frontdesk-mic-01",
    "session_id": "abc-789"
  }
}
